## Current Context

GuildLogger2 is being refactored from a legacy Flask codebase to:

- Backend: Go + Echo
- Frontend: React + Vite
- Database: MongoDB
- Integrations: Discord OAuth2 + Discord bot workflows

## Documentation Policy

- These documents reflect the target GuildLogger2 design, not the legacy source project.
- Mark incomplete features as Planned or In Progress instead of documenting them as implemented.
- Update docs in the same PR whenever behavior, API contracts, or environment settings change.
